# Synapse AI - Design System

> This document defines the visual identity and UI decisions for Synapse AI.
> Every new screen and component should follow these guidelines.

---

# Design Philosophy

Synapse AI should feel:

- Premium
- Modern
- AI-Native
- Elegant
- Minimal
- Professional
- Fast
- Highly Interactive

The interface should prioritize clarity and usability over unnecessary visual effects.

---

# Brand Identity

Synapse AI is not just another dashboard.

It combines:

- Social Platform
- Team Collaboration
- CRM
- AI Assistant
- Project Management
- Analytics
- Payments

The UI should communicate:

- Intelligence
- Trust
- Productivity
- Innovation

# Border Radius

Default

16px

---

# Shadows

Use soft shadows only.

Avoid harsh shadows.

Prefer glow accents over heavy shadows.

---

# Cards

Cards should have:

- Soft border
- Rounded corners
- Slight hover lift
- Subtle glow
- Clean spacing

---

# Buttons

Buttons should include:

- Smooth hover animation
- Soft glow
- Slight scale on hover
- Ripple click effect

Primary buttons use the Primary Color.

---

# Forms

Forms should include:

- Rounded inputs
- Animated focus border
- Floating labels (where appropriate)
- Clear validation messages

---

# Navigation

Application uses:

- Left Sidebar
- Top Navigation Bar

Sidebar should support collapse and expand animations.

---

# Motion & Animation

Animations should feel smooth and intentional.

Include:

- Smooth page transitions
- Card hover lift
- Button ripple
- Mouse hover glow
- Scroll reveal
- Fade animations
- Loading skeletons
- AI typing animation
- Smooth modal transitions

Animation duration:

200ms–300ms

---

# Background Style

Background should include:

- Deep dark gradient
- Soft radial glow
- Subtle AI-inspired decorative elements

Avoid excessive neon effects.

---

# Responsive Design

Support:

- Desktop
- Laptop
- Tablet
- Mobile

Responsive design is mandatory.

---

# UI Principles

Consistency over complexity.

Elegance over flashy effects.

Smooth interactions over excessive animations.

Readable interfaces over decorative designs.

Every screen should look like it belongs to the same product.
